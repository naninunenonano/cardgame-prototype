# cardgame-prototype — 盤面試作 Ver.0.11

緑・青・無色を組み合わせられる、静的HTML/CSS/JavaScriptのカードゲーム試作です。Bot戦と壁打ちに対応し、外部アカウント・APIキー・データベース・ビルドは不要です。この更新は作業ブランチとPRで確認するためのものです。mainへのマージ・GitHub Pages更新・公開範囲の変更は行いません。

## 起動と操作

同じフォルダにあるindex.htmlをブラウザで開きます。ファイルプレビューでは操作できない場合があるため、PCのブラウザまたはローカルHTTPサーバーで開いてください。

```sh
python -m http.server 8080
```

`http://localhost:8080/`で画面のVer.0.11を確認します。iPhoneの実機Safari操作は未確認です。

開始画面で自分と相手のデッキ、および壁打ち／Bot戦を選択します。人間はP1、BotはP2。Bot戦は先攻ランダム、壁打ちは自分のターンだけを繰り返します。カードをタップ→使用／攻撃／拡大→対象・配置先・支払いを選んで確定。ドラッグ操作は不要です。保留した効果は「選択を再開」から戻れます。

各プレイヤーの山札・土地デッキ・トラッシュ・土地トラッシュ・除外・サイド・チェック・キャラは小さな枚数ボタンから一覧へ。ユニット7枠・設置物・手札は領域内の横スクロールで、カードが増えても画面全体の横幅を広げません。未使用／使用済みは向きと文字で表示。使用カードは約2秒ずつ順番に表示し、公開履歴から能力全文を再確認できます。Bot戦では相手の非公開手札・盾・予顕の中身を表示しません。決着後も盤面と履歴を確認でき、再戦またはデッキ選択へ戻れます。

壁打ち側には手動移動・追加・向き／召喚酔い切替・手動ドロー等の補助操作を残しています。Bot戦の通常操作にはありません。

## 今回の基本ルール

- 初期手札5枚。両者1回ずつ、0〜5枚を選んで「山札の下へ→同数ドロー→シャッフル」。交換個体はその引き直しで戻りません。両者完了後、メインから裏向き盾7枚を配置します。
- 手札上限なし。エンドでも枚数を理由に捨てません。ワルスラのようなカード効果による捨て札は行います。
- ターン開始は自分の場と土地のアンタップ・召喚酔い解除→帰還予約→通常ドロー→土地1枚自動配置。先攻の第1ターンだけドローなし、土地は第1ターンも配置。メイン1→アタック→メイン2→エンド。終了時効果は処理します。
- 土地は独立した土地デッキ20枚。毎ターン、上から1枚を未使用でマナへ。効果による追加は別枠。土地とメインカードを混ぜません。土地は破壊・退場で土地トラッシュへ。土地デッキが必要時に空なら土地トラッシュだけを戻してシャッフルし、両方空ならその配置だけ省略します。
- メインが空なら通常トラッシュを戻してシャッフル。リフレッシュのペナルティなし、山札切れによる敗北なし。手札・場・盾・除外・土地トラッシュ・解決中のカード・一時確認中のカードは戻しません。複数ドロー等は続け、両方空なら可能な枚数で止めて不足を表示します。
- ユニット上限7枠。満杯なら対象を選んで上書きし、元はトラッシュへ。設置物は別領域で上限なし。支払い・配置確定前の取消ではカードを移動しません。
- 通常攻撃は本体。ユニット攻撃にはマッハファイター等の能力が必要です。ブロックは未使用ブロッカー1体まで。攻撃・ブロック・自身を横向きにするマナ能力は使用済み状態を共有します。
- シンボル0でも攻撃可能。ブレイク数は0、攻撃回数には含みます。通常はシンボル数＝ブレイク数。盾0枚の本体へ攻撃が通れば勝利し、最後の盾を割っただけでは勝ちません。ブロック・引き付けによる戦闘は直接勝利になりません。
- 同パワーでは攻撃側が勝ち、低い側をトラッシュへ。ダメージ蓄積なし。ブレイクした実個体を先に確定して手札へ移し、トリガーは持ち主が順を選択。途中で追加した盾を同じ攻撃で割り直しません。
- コストは不特定と五色を分離。場の同色シンボルで色指定だけを軽減し、最低1点を残します。不特定は軽減しません。横向きでも供給、消費・タップなし。土地は軽減シンボルなし。上書き元は支払い時点では数えます。無色シンボルはどのコストも軽減せず、ブレイクにだけ対応します。ジルの固有軽減は別処理です。
- 支払いは未使用土地と、召喚酔いでない未使用のマナ能力ユニットから。必須色を先に確保した案を変更可能。マナプールは設けません。確認時に対象・配置先・支払い元を再検証し、二重確定を拒否します。

## デッキ編集・保存

開始画面の「デッキ編集・保存」から、文明フィルター、名前検索、カード詳細、＋／−で枚数を編集します。デッキ名を設定して保存、読み込み、複製、削除が可能。ブラウザのlocalStorageに複数保存し、再読み込み後も維持します。保存できない環境・不正な保存形式ではエラーを表示し、元のデータを自動で上書きしません。同じ形式の旧配列データも読み込めます。以前の版にはデッキ保存機能がなかったため、試合途中の旧状態は取り込みません。

自作は**メイン60枚（土地なし）＋独立した土地20枚**として検証します。緑・青・無色8種を自由に組み合わせられます。緑・青の基本土地の配分を編集でき、基本土地に同名上限はありません（合計20枚は維持）。サイドボードは既存の別枠10枚、プリセットでは空。今回はサイドの新規カード・特殊な切り札・サイド編集画面を追加しません。

既存の緑40枚・青40枚プリセットは構成を変えず、読み取り専用の例外として残します。緑はバハムート1枚・他13種各3枚。青はシェイパー1枚・他13種各3枚。ツヴァイランサーは3枚のままです。複製後は自作60枚として検証するため、20枚加えてから対戦で使えます。

メインの同名上限は3枚、バハムート・シェイパー・ジル・ペリドットは各1枚。上限はカードデータで保持し、デッキ生成・開始時にも検証します。運命3種・トークン・未実装の赤白黒は編集候補に含めません。未完成の構成も下書き保存できますが、対戦開始は拒否します。人間・Bot・壁打ちの両側で保存済み自作デッキを選べます。開始時の構成はコピーされ、編集後に対戦中のカードが変わることはありません。

## 運命：生成と使用後消滅

ジルの登場時に、説明・コスト・追加効果・消滅を表示した3枚から直接1枚を選び、固有IDを持つ専用呪文を手札へ生成します。

| 運命 | 不特定コスト | 効果 | 自分の場にジルがいる場合 |
| --- | --- | --- | --- |
| 運命の気まぐれ | 1 | 1枚ドロー | この効果で引いた個体の使用コストを1にする |
| 運命の翼 | 4 | 山札上から裏向き盾1枚追加 | さらに2枚ドロー |
| 運命の逆転 | 8 | 自分の追加ターンを予約 | ジルがいない場合のみ相手も追加ターンを得る |

3種すべて、使用後は専用の`vanish`処理で領域配列から除去します。トラッシュにも除外にも置かず、どの領域にもカード個体が残りません。消滅IDの監査記録と公開行動の履歴は残しますが、回収・予顕使用・リフレッシュの候補にはなりません。使用を打ち消された場合も使用後消滅し、支払いは戻しません。支払いキャンセルでは未使用のまま手札に残します。

運命の消滅は、トークン退場や予顕・ペリドットの除外予約とは別処理です。通常のデッキ編集では採用できず、消滅したカードを再利用する経路はありません。

## 今回明示した処理順・境界

- 追加ターンは効果の解決順にFIFOで予約し、通常の次の手番より先に消化します。ジル不在の逆転1回なら「使用者の追加→相手の追加→本来の次の手番」。追加ターンでも自分の回復・ドロー・土地・召喚酔い解除・終了時効果を通常どおり処理します。通常交互進行の位置は保持します。壁打ちでは相手の追加分を記録だけにし、相手ターンを発生させません。
- 気まぐれのジル条件はドロー解決時に判定。コスト1は色不要で、予顕する費用とは別です。期限が指定されていないため、その個体の通常／予顕後の使用費用の変更を移動後も保持します。軽減前の元コストは別に残し、母なる大地などの元コスト判定は変更しません。
- 帰還はアンタップ後・通常ドロー前に1体ずつ選択。満杯なら上書きを確認します。帰還はカードの使用ではなく、対抗呪文の対象にしません。帰還時には登場時の自己除外を繰り返さず、設置物のユニット登場誘発は行います。以後、攻撃成功で再び除外・予約できます。
- 進化は1枠、最上段の能力・パワー・シンボルのみ。召喚酔いなしで、進化元の向きを継承。ツヴァイランサーは青限定、ワルスラは文明不問。退場では実カード全層を移動し、山札上へ戻す場合は持ち主が順を選びます。進化を打ち消しても元は残ります。
- ワルスラは攻撃宣言・使用済み・攻撃回数加算→任意ドロー／選択捨て札→攻撃先への戦闘／ブロックの順。効果を選んでいる間、次の攻撃は始めません。
- ホネンビーは任意の3枚送りと回収を一まとまりにし、新しく送った個体も候補に含めて回収後に空のメインをリフレッシュします。対象がなければ回収を省略して続けます。除外カードは候補に含めません。
- カイザーは0〜4枚を選択可能。未使用の土地を選んでも状態を戻すだけで、マナを新たに貯留しません。複数体は順に処理します。
- 勝敗が確定したら通常操作・効果キュー・演出・Botを停止します。盾0枚の直接攻撃勝利は維持し、山札切れを勝敗へ使いません。

## 既存の緑・青とBot

既存カードのコスト・能力・採用枚数は維持。緑の加速は土地デッキから未使用で追加し、修復・フォージュン・パンツァー・ドルツヴァイの条件は場の土地だけを参照します。バハムートは本人以外の両者ユニットと設置物をトラッシュへ、テミスはユニットだけです。

青の予顕コストと効果は維持。裏向きで除外し、予顕したターンには使えず、次のターン以降も本来の使用タイミングに従います。対抗呪文は待機解除後の直後の相手ターンでも応答可能。無料使用にも応答でき、対抗への対抗は後から解決。支払い済みコストは返却しません。土地自動配置・既存の能力・予顕として伏せる操作へ割り込みを拡大しません。

土地バウンス・土地手札はありません。スパイラル・ゲートとスノーマンの対象は両者のユニット／設置物だけです。パルピィは攻撃禁止を維持。コスモビューは使用前の実際の手札10枚でG・ゼロを判定。ベガスは個体ごとの任意終了時ドローを維持し、その後も手札は上限なし。トークンは場を離れれば消滅し、実カードとして山札等へ混ぜません。

Botは情報投影だけを受け、人間と共通の合法な操作・支払い・効果処理を使います。追加カードの選択・進化・帰還・土地回復・回収を処理し、入力待ち・応答待ち・演出中は進みません。公開盤面、自分の手札、効果で許可された一時確認以外の秘密情報は渡しません。リセット／決着時に旧タイマーを無効化します。

判断は点数による貪欲評価です。運命の選択、全体除去の損得、回収カードの価値などを評価しますが、追加ターンを含む多段コンボや将来の最善手を完全探索しません。
