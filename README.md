# cardgame-prototype — 盤面試作 Ver.0.3

60枚の赤単色仮デッキから開始し、各自1回のマリガンを選んでシールドを置く、手動の壁打ちツールです。マナは土地のみです。

## 起動・操作

GitHub Pagesの既存URL、またはindex.htmlをブラウザで開きます。ビルド・APIキー・外部アカウントは不要です。ローカルではstyle.cssとapp.jsも同じフォルダに置きます。iPhoneのファイルプレビューはJavaScriptが動かないことがあるため、公開URLをSafari等で開いてください。

開始時はプレイヤー1の初期手札を表示します。交換するカードをタップして複数選択し、「○枚交換する」で確定します。再タップで解除できます。「交換せず開始」でも完了になり、次のプレイヤーに進みます。両者が完了してから壁打ち画面が開きます。プレイヤーのタブで未完了の相手へ切替も可能です。

壁打ちでは両者のカードを操作できます。カードをタップし、下の操作欄で移動先を選んで移動。手札は「マナに置く」でも移動できます。土地以外のマナ配置は、専用操作・汎用移動・追加のすべてで拒否します。

表裏・縦横切替、内容の拡大確認、一覧選択、ドロー、シャッフル、山札上下、仮カード追加・削除、マナ一括縦向き、手札公開範囲切替、コンパクト表示を引き継ぎます。通常移動・ドローで表裏と縦横を保持するため、必要に応じて表裏を変更してください。裏向き内容確認は表裏を変えません。手札の両者公開でも個別の裏向き状態は維持します。

「初期状態へ」は確認後に両者の配置、追加カード、選択、マリガン状態を捨て、60枚の生成・シャッフル・初期手札からやり直します。キャンセルは状態を変えません。保存状態の読込機能はなく、再読み込みでも新規開始します。

## デッキ・カードデータ

両者は同じ構成です。赤・1コスト〜赤・12コストが各3枚（通常36枚）、赤の基本土地24枚、合計60枚。生成時に60枚・基本土地以外の同名3枚までを検証します。基本土地はこの同名制限から除外します。

カードはid・name・type・color・cost・basic・origin・faceUp・restを保持します。同名もidで個体を区別し、originで初期の所属を追跡します。基本土地のcostはnullで、配置支払いはありません。効果・能力値は持ちません。

サイドボードは旧ルリグデッキと同じ領域で10枚枠です。初期は空で、独自のカードを生成しません。仮カード追加で試せます。上限10枚以外の構築・同名制限はサイドボードに適用しません。追加カードは壁打ち補助としてorigin=nullになり、生成した60枚と区別します。自由なデッキ編集画面はありません。

## 開始処理

1. 60枚を生成・検証し、プレイヤーごとにシャッフル。
2. 上から7枚を表向きで手札へ。山札53枚、シールドはまだ0枚。
3. 各自0〜7枚を選んで1回交換、または交換せず完了。
4. 交換対象を山札の下へ戻し、先に上から同数引いてから山札をシャッフル。
5. 両者完了後に、それぞれ上から7枚を裏向きのシールドへ配置。
6. 通常操作を解放。各自は手札7・シールド7・山札46、その他の領域は空。

通常操作は開始準備中に非表示／無効です。移動・追加も状態処理で拒否します。マリガンは同期処理の冒頭でプレイヤーを完了扱いにし、連打や古いボタンで再実行しません。先にシールドを置いたり、引き直す前にシャッフルしたりしません。

配置回数、マナ量・自動支払い、軽減シンボル、効果・能力値、戦闘・勝敗、Bot、オンライン対戦は追加していません。

## 構造

app.jsのCONFIGで初期枚数・上限、ZONESで名称・領域、buildDeckで仮デッキを定義します。finishSetupにシールド配置のタイミングをまとめています。CSSのgrid-template-areasで盤面配置を変更できます。既存の領域キーextra（サイドボード）、life（シールド）、energy（マナ）を再利用しています。

## 検証

- node --check app.js：成功。
- node model-test.cjs：成功。96回の開始テストで構成36＋24、0/1/3/7交換、正しいドロー元とシャッフル順、戻した個体を再ドローしないこと、マリガン1回制限、シールド配置時期、最終7/7/46、各自60個体、開始中の操作制限、土地限定、サイドボード枠、リセットを確認。
- node dom-test.cjs（開発用jsdom）：成功。複数選択／解除・枚数、古いボタンの再実行拒否、開始UIの制限、名称、公開手札、専用／汎用の土地限定、マナ枚数、追加、リセットと0枚交換を確認。
- node browser-test.cjs（開発用Playwright＋Chromium）：成功。幅390px・タッチ有効のChromiumで一部／7枚／0枚交換、交換せず開始、7/7/46、60個体、操作制限、両者手札公開、マナ操作、リセットを検証。390pxと1280pxでページ横幅が広がらず、JavaScriptエラーがないことも確認。CHROMIUM_PATHでローカルの実行ファイルを指定できます。

実機iPhone・iOS Safariは未確認です。ヘッドレス環境に日本語フォントがないため、その環境のスクリーンショットでは日本語が欠けます。日本語の文字列・ラベルはDOMで確認しています。

テスト用ライブラリはアプリの実行には不要です。ブラウザテストのスクリーンショットは既定で/tmpへ保存します（SCREENSHOT_DIRで変更可能）。公開ではCSS・JSのURLにバージョンを付けて更新します。mainと既存のPages公開ブランチを同期し、リポジトリの公開範囲は変更しません。
