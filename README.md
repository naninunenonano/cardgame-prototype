## 戦闘と進行

- 初期ライフ30、初手5枚。マリガンは1回、選択した0〜5枚を山札下へ戻し、同枚数引いてシャッフル。旧シールドの配布・ゾーン・ブレイク・トリガーはありません。
- クリーチャーは攻撃力／現在体力を表示し、詳細に最大体力を表示します。既存パワーを1000で割り、攻撃力・最大体力へ同じ数値で変換しました。トークン・進化も同じです。
- プレイヤーへ攻撃が通れば攻撃力分のライフダメージ。ライフ0以下で敗北します。
- 通常攻撃は相手プレイヤーか横向きクリーチャー。戦闘では互いの攻撃力分のダメージを同時に受け、現在体力0以下の双方を破壊します。ダメージはターンをまたいで残ります。
- 攻撃・ブロックで横向きになり、自分のターン開始にアンタップ。ブロッカーは縦向きの1体が本体への攻撃を自身へ変更する既存方式です。存在するだけで攻撃を制限しません。パンツァーの引き付け能力は明示的な例外として維持します。
- 召喚酔い中は攻撃・自身を横向きにするマナ能力を使えません。スピードアタッカーは通常の対象へ攻撃可能。マッハファイターは登場ターンに相手クリーチャーの向きを問わず攻撃可能ですが、本体へ攻撃できません。
- 進化は元の向きを継承し、召喚酔いなし。新しい最上段の体力で登場します。場を離れて再登場したクリーチャーも体力を初期化します。
- ドルツヴァイは攻撃力・最大体力＝自分のマナ枚数。マナ増減時は受けたダメージ量を維持し、現在体力0以下なら破壊します。
- 色付きシンボルは対応する色指定コスト軽減専用。横向きでも供給し、消費せず、原則最低1を残します。不特定コスト・攻撃可否・ダメージに影響しません。マナゾーンのカードはシンボルを供給せず、本人の使用コストに本人を数えません。無色シンボルは削除しました。ジルの明示的な不特定軽減は別処理として維持します。
- 山札からカードが必要な時に山札が空なら通常トラッシュだけをシャッフルして補充し、自分で選んだマナ2枚（不足時は全枚数）を除外して中断処理を再開します。トークンは消滅し、ライフは減りません。再利用可能なトラッシュがなければ敗北します。
- ターン開始・アンタップ→ドロー→マナチャージ→メイン1→アタック→メイン2→エンド。先攻初回ドローなし。マナチャージは手札の通常カードを最大1枚、任意で配置し、そのままメイン1へ進みます。カード自身の文明の1マナを供給し、支払いで横向き、次の自分ターン開始に戻します。無色マナは色指定コストに使えません。
- ユニット7枠、手札上限なし。効果によるマナ追加は通常チャージ回数を消費しません。新仕様・変更カード・保存互換の詳細は [MANA-v0.16.md](MANA-v0.16.md) を参照してください。

## デッキ・既存機能

通常40枚・サイドボード10枚枠＋独立したシールド4枚。プリセットのサイド内容は従来どおり空で、シールド専用2種類とシールド編集を追加し、既存サイド枠も編集画面から確認できます。通常同名3枚、ジル・ペリドット・ツヴァイランサー・シェイパー・母なる大地・修復・バハムートは各1枚です。緑・青の公式プリセットだけが元の構成に対する既存例外を持ちます。複製後は通常制限を適用します。

デッキ編集は文明・種類・名前検索、詳細、枚数編集、保存・複製・削除に対応。localStorageへ保存し、不正デッキは下書きとして保持しますが開始を拒否します。インスタント・対抗呪文・進化・トークン・運命生成と使用後消滅・追加ターン・ペリドット帰還・上書き配置・カード拡大・2秒の使用表示・公開履歴を維持しています。Botには相手手札や山札順を渡しません。壁打ち補助はBot戦には表示しません。

## ピルルク・サイドボード

開始画面の自分／相手のサイド構成で「ピルルク構成10枚」を選択できます。従来プリセットは構成を変更せず維持。デッキ編集では自作／複製デッキに専用の10枚を設定・編集・保存できます。

ピルルクは専用領域でLv1→Lv4へ成長（不特定1/3/5/7）。成長もサイドの自分ターン1枚制限に含み、Lv2直後のバイスのみ追加処理です。Lv4は実際の相手捨て札1枚につき1ドロー＋アクア・ガード、サイドの不特定3軽減。サイド呪文・退場したサイドクリーチャーはサイドで使用済みとなり、通常再使用不可です。

5000VTは両者クリーチャー数とLv4能力で不特定を0まで軽減し、登場時に現在攻撃力5以下を両者バウンス。次の相手ターン中は、通常・無料・特殊登場・トークンを含め攻撃力5以下を出せません。VTが離れても制限を保持し、指定ターン終了時に解除します。

ガンヴィート、アレグルの覚醒前数値・シンボルは仮設定、成長Lv3/Lv4のコストは試作値です。5000VTの青シンボル1も仮設定と明記しています。全10枚・覚醒・革命チェンジの仕様、仮設定、保存、テストの詳細は [SIDEBOARD-v0.15.md](SIDEBOARD-v0.15.md) を参照してください。

Ver.0.18では対抗呪文を青1＋無色2の呪文専用インスタントへ変更し、予顕を廃止しました。壁打ちの終了時に操作側を切り替える補助を追加し、相手終了時の覚醒やVT制限を確認できます。

## 新シールドデッキ

緑・青とも《リアクティブアーマー》2枚＋《知恵の恵み》2枚。通常・サイドとは別枠の4枚で、同名上限なし。専用カードの他領域採用、通常カードのシールド採用は禁止です。開始時は4枚とも裏向き・未使用。使用後はその位置で表向きとなり、山札・トラッシュへ移りません。

各誘発タイミングでは最大1枚を任意使用、または全て見送ります。1枚を選ぶとイベントIDの受付を閉じ、残りを続けて使うことはできません。異なる攻撃宣言・ライフ減少では同じターンにも再び1枚選べます。マナ不要で、ターン1枚制限ではありません。

- リアクティブアーマー：自分を狙った攻撃の宣言時ライフが10以下なら、ダメージ前に攻撃クリーチャーを破壊。宣言時12なら、攻撃後10以下になる見込みでも使えません。破壊耐性は尊重します。
- 知恵の恵み：実際のライフ減少1イベントにつき任意2ドロー。戦闘・カード効果に対応。0ダメージ・回復では誘発せず、致死ダメージ後は選択を開きません。

自分のカードは裏向きでも詳細確認可能。相手の裏向きカードは名前・条件・効果を隠し、表向きだけ公開します。壁打ちは「手動確認対象」で見る側を切り替えられます。Botの情報投影にも同じ秘匿を適用します。

シールド編集は合計4枚を表示し、0〜4枚の配分を保存・読み込み・複製できます。古い保存にshields項目がない場合は2＋2を補います。明示的な0枚や不正構成は勝手に置換せず、警告して開始を拒否します。保存キーを変えず既存デッキを保持します。

## 5枚の確定効果

| カード | 現在の効果 |
|---|---|
| 竜の闘気 | 通常デッキ上1枚を未使用でマナへ追加→2ドロー→3回復 |
| 修復 | 自分の使用済みシールド1枚を任意で裏向きへ→3回復。対象なし・見送りでも回復 |
| エメラル | 登場時、相手の裏向きシールド1枚を選び自分だけ確認。表裏・配置を変えない |
| ホーリー・メール | ライフ4回復 |
| 運命の翼 | 自分の1体を＋2/＋2。攻撃力・最大体力・現在体力を2増加。ジルがいれば2ドロー、使用後消滅 |

回復上限30。修復は緑3、最大2軽減、同名1枚制限を維持。運命の翼の強化は場にいる間保持し、マナ参照クリーチャーでも加算分を維持します。旧盾追加・旧シールドトリガーは復活していません。変更とテストの詳細は [SHIELDS-v0.14.md](SHIELDS-v0.14.md) を参照してください。
