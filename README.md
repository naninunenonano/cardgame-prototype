# cardgame-prototype — 盤面試作 Ver.0.7

緑単色60枚で、自分（プレイヤー1）のターンだけを繰り返す壁打ち試作です。公式画像・外部API・アカウント・ビルドは不要です。

## 起動・基本操作

[GitHub Pages](https://naninunenonano.github.io/cardgame-prototype/?v=0.7)を開きます。ローカルでは、index.html・style.css・mana.js・cards.js・game.js・app.jsを同じフォルダに置き、index.htmlをブラウザで開きます。iPhoneではファイルのプレビューでなく、Safari等で公開URLを開いてください。

両者のマリガンを確定すると、盾を7枚ずつ配置し、先攻の第1ターンを開始します。カードをタップして操作を選びます。ドラッグは不要です。

- ユニット：「場に出す」→配置先（満杯なら上書き対象）→支払い元・色を確認→確定。
- 呪文：「呪文を使用」→支払い確認→対象や基本土地をタップして、順番に解決。ユニット枠は使いません。
- 土地：「マナに置く」。通常配置はメイン1・2を合わせて1ターン1枚。効果追加は別枠です。
- 基本土地検索：表示された個体を1枚選ぶか、0枚を選んで続行。検索後は山札をシャッフルします。
- 攻撃：アタックフェイズに自分の未使用ユニットを選択。対象選択が必要なら選び、相手本体への攻撃では防御側のブロックを手動選択します。
- シールドトリガー：割れた盾を先に手札へ移し、持ち主が処理順・使用の有無を1枚ずつ選びます。ユニットの無料配置も上書き可能です。
- 「手動移動」・追加・縦横・召喚酔い切替・ドロー・回復等はルール外の補助です。処理中は使えません。手札公開、拡大・裏向き確認、領域一覧、山札上下、除外も維持しています。

「盤面全体を見る」でカード表示を縮められます。手札・マナは領域内スクロール、ユニット7枠はスマートフォンで折り返します。カードの能力全文は「拡大・内容確認」で読めます。選択画面を閉じても、検索・戦闘・トリガー・手札調整は上部の「選択を再開」で戻れます。支払い画面を閉じた場合は未確定の支払いを取り消します。

## 開始設定・ターン

両者に同じ緑12種類各3枚＋基本土地24枚＝60枚。基本土地以外の同名3枚までを生成時に検証します。各個体にIDがあり、色・種類・不特定コスト・各色コスト・供給シンボル・効果列等を持ちます。

初手7枚、各自1回のマリガン（0〜7枚）。交換対象を山札下へ戻し、同数ドローしてからシャッフルするため、その引き直しでは交換対象が戻りません。両者完了後、初期盾7枚を裏向きで置きます。初期配置は各自手札7・盾7・山札46。盾7は初期値で、追加後の上限ではありません。サイドボードは空の10枚枠、プレイヤーキャラも空で、中身・能力を追加していません。

試作フェイズ順は「アンタップ→ドロー→メイン1→アタック→メイン2→エンド」。アンタップとドローはターン開始時に自動処理します。自分の場と土地を未使用へ戻し、召喚酔いを解除、通常土地配置回数をリセット。先攻第1ターンは追加ドローなし、以降1枚。相手の自動回復・ドロー・ターン・操作対象切替はありません。

土地・カードの通常使用はメイン1・2。土地を戻しても配置済み状態は戻りません。エンドだけ手札超過を確認し、選んで7枚までトラッシュへ送るまで次のターンへ進みません。相手は壁打ち中にエンドを迎えないため、相手の手札増加では即時調整しません。

ドローで最後の1枚を引いた瞬間、持ち主が山札切れで敗北し、残りの効果を停止します。解決中の呪文はトラッシュへ送ります。リフレッシュなし。盾追加・検索など、ドロー以外で山札が空になっただけでは敗北条件を拡張しません。盾0枚への攻撃は記録だけで、勝利条件は追加していません。

確認付きリセットで、配置・ID・マリガン・ターン・土地回数・使用済み・召喚酔い・効果待ち・操作選択・結果・ログを初期化します。再読み込みも新規開始です。

## 軽減・支払い

不特定コストと五色の必要数を別管理。場のユニット・設置物の同色シンボルは、色指定部分だけを軽減します。緑は最低1点残し、不特定は軽減しません。横向きでも供給し、シンボルは消費・タップしません。土地はシンボルを供給しません。出す本人は支払い前に場にいないため軽減元にならず、上書き元は支払い時点では場にいるため数えます。

土地は未使用の1枚でその色1点。極楽鳥・ラノワールのエルフも、未使用かつ召喚酔いでなければ支払い元にできます。極楽鳥は色を選択します。マナ能力・攻撃・ブロックは同じ使用済み状態を共有します。マナプール・独立した生成操作はありません。

必須色を先に確保し、残りで不特定を満たす自動案を提示し、タップで変更できます。確定時はカード・配置先・上書き元・支払い元の所属／向き／召喚酔い／色／重複と軽減後コストを再検証し、まとめて確定。キャンセル・支払い不能・二重確定では消費しません。

上部とマナ付近に使用可能な支払い元、任意色源の数、各色の候補数を表示。極楽鳥は複数色の候補に数えますが、1回に出すのは選んだ1色だけです。候補数の合算は貯留マナを意味しません。手札の使用可否にも軽減と使用可能なマナ能力を反映します。

| 豊潤フォージュン | 2＋1 | — | — | 基本土地1枚まで→シャッフル→追加後の土地5枚以下なら1ドロー |
| 竜の闘気 | 4＋1（仮値） | — | — | 基本土地1枚まで→シャッフル→2ドロー→盾1追加 |
| 青銅の鎧 | 3＋1（色指定は仮値） | 2000 | 1／1 | 登場時に基本土地1枚まで→シャッフル |

基本土地検索は基本土地だけを候補にし、0枚選択も可能。検索対象がなくてもシャッフルして残りの効果を続けます。効果の土地は未使用で配置し、通常の土地配置回数を消費しません。バハムートは本人・土地・盾・プレイヤーキャラ・サイドを対象にしません。

## 戦闘・トリガーの試作処理

ユニット上限7枚。満杯なら上書き元を選び、支払いと同時に旧カードをトラッシュへ送れます。呪文は枠を使わず、解決後トラッシュへ送ります。

通常の攻撃は本体のみで、未使用・召喚酔いでないことが必要です。マッハファイターは出たターンだけ、召喚酔いでも相手ユニットを縦横問わず攻撃可能。本体へは召喚酔いを無視できず、翌ターン以降はこの能力で相手ユニットを直接攻撃できません。有効期間はカードデータのdurationで変更できます。

パンツァーが相手にいれば横向きでも強制対象となり、複数なら攻撃側がその中から選びます。ブロッカーではありません。通常の召喚酔いを無視する能力でもありません。

本体攻撃では、未使用のブロッカー1枚でブロックするか選べます。召喚酔いはブロックを妨げません。今回の緑60枚にブロッカーを独自追加していません。確認用は手動追加のブロッカー欄で用意できます。

戦闘はパワーだけを比較し、低い側をトラッシュへ。同値は攻撃側有利。ブロッカーは使用済みになり、直接攻撃されたユニットはそれだけでは使用済みになりません。盾へ貫通処理はせず、ダメージ蓄積もありません。ドルツヴァイは攻撃側の同値勝利でも土地追加を行い、土地の増減でパワーを即更新します。

ブロックなしならカードのブレイク値だけ盾を手札へ。ノーシンボルは0枚。今回の試作ではシールド領域の先頭から必要枚数を先に確定し、全個体を手札へ移動後、その時点で条件を満たすトリガーを好きな順に1枚ずつ処理します。途中で追加した盾は同じ攻撃で割りません。通常ドローではトリガーを起こしません。

トラッシュと除外ゾーンは別領域で、両方に一覧があります。除外は明示的な補助移動だけ。横向きになっただけのカードは場に残します。Bot・オンライン対戦・未指定能力・ほか4色の新デッキ・サイドやキャラ能力は追加していません。

## 構造・検証

- cards.js：色・種類・緑カード定義・データによる効果列・デッキ構成。旧赤デッキ定義も再利用可能な状態で保持。
- mana.js：表示から独立した五色コスト／マナ判定。
- game.js：軽減・支払い元割り当て・逐次効果キュー・検索・トリガー・戦闘・ターン。
- app.js／style.css：日本語UIとタップ操作。

`node model-test.cjs`で緑の18統合テスト群（開始、マリガン、軽減、支払い・取消、12種の効果、閾値、戦闘、トリガー、個体保存、ターン・リセット）を確認。`node browser-test.cjs`で既存機能の回帰、`node green-browser-test.cjs`で緑の検索・極楽鳥の色選択・トリガー順序・相手持ち主の検索・無料上書き等を390pxタッチと1280pxのChromiumで確認。`node dom-test.cjs`はjsdomで手動追加フォーム・マリガン連打・リセット・文言を確認します。

開発テストのみNode.js、Playwright、jsdomとChromiumが必要です。CHROMIUM_PATHでブラウザ実行ファイルを指定できます。ヘッドレス環境は日本語フォントがないため、日本語文言はDOMでも検証しています。実機iPhone／iOS Safariでの操作と描画は未確認です。
