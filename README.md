# cardgame-prototype — 盤面試作 Ver.0.9

メイン40枚と土地20枚を別々に持つ、緑単色の壁打ち試作です。開始画面で壁打ち／Bot戦を選べます。壁打ちは自分（プレイヤー1）のターンだけ、Bot戦は人間P1とBot P2が交互に進行します。Bot戦は先攻をランダムに決めて表示し、壁打ちは従来どおり先攻で開始します。公式画像、ビルド、外部API、アカウントは不要です。

## 起動・操作

[GitHub Pages](https://naninunenonano.github.io/cardgame-prototype/?v=0.9)をブラウザで開きます。ローカルではindex.html・style.css・mana.js・cards.js・game.js・bot.js・bot-runner.js・app.jsを同じフォルダに置き、index.htmlを開いてください。iPhoneではファイルプレビューではなくSafari等で公開URLを開きます。

壁打ちでは両者のマリガンを手動選択。Bot戦ではBotのマリガンは自動で、人間は自分だけ選びます。両者完了後に盾7枚をメインから配置し、先攻の第1ターンを開始。開始直後は両者の手札7・盾7・メイン残り26枚、先攻だけ土地1枚が場へ出て土地デッキ残り19枚（後攻は20枚）です。後攻は自分の初回ターンに通常ドローも行います。

- 手札をタップ→「場に出す／呪文を使用」→配置先・支払い元・色を確認→確定。ユニット7枚満杯なら上書きできます。呪文は枠を使わず、設置物は専用領域に上限なしで残ります。
- 毎ターンの土地は自動です。手札からの通常土地配置ボタンは廃止しました。効果の土地追加も自動で、検索・土地選択画面はありません。
- 母なる大地：使った人が両者から対象ユニットを選ぶ→対象の持ち主が自分の手札から無料で出すカードか「出さない」を選ぶ→配置先を選んで確定。
- アタックでユニットを選んで攻撃。必要なら攻撃対象を選び、本体攻撃では防御側のブロックを手動選択します。トリガーも持ち主が順番と使用の有無を選びます。
- 各領域の一覧で重なるカードを選べます。土地デッキは通常表示・一覧とも裏向きです。選んだ個体の内容は壁打ちの拡大確認で見られます。
- 土地の退場確認は、マナの土地を選び「手動移動」で土地トラッシュへ。通常トラッシュを選んでも土地は土地トラッシュへ振り分けます。補助操作の削除は個体自体の削除です。
- 「手動移動」・追加・縦横／召喚酔い切替・ドロー・回復等は壁打ち専用のルール外の補助です。Bot戦ではUIから外し、ルール側でも拒否します。土地をメインへ、通常カードを土地デッキ／土地トラッシュへ混ぜる移動は拒否します。

Bot戦では上部に現在の手番・先攻・Botの進行を表示します。人間のブロック・トリガー・母なる大地の選択では入力を待ち、Bot側の選択は自動です。人間にブロッカーがいなければブロック選択を省略して攻撃を解決します。カード使用・攻撃・効果の詳細は操作ログでも追えます。対戦中の「初期状態へ」は現在のモードで再開始、「モード選択へ」は確認後に現在の対戦を終了します。

ドラッグ不要。手札・マナは領域内スクロール、ユニット7枠はスマートフォンで折り返します。「盤面全体を見る」で縮小表示、選択カードの「拡大・内容確認」で能力全文を読めます。手札公開切替、山札上下、シャッフル、トラッシュ／除外一覧も維持しています。

検索を使っていた旧カードは土地デッキからの自動追加に変更済みです。選択中の効果・戦闘・トリガー・エンド調整を閉じた場合、上部の「選択を再開」で戻れます。支払いは閉じるとキャンセルし、無料配置の取消は手札に残して効果を続けます。

## 開始・フェイズ

各デッキを別々に生成・シャッフルし、メインから初手7枚。マリガン各1回、0〜7枚を選び「山札下へ→同数ドロー→シャッフル」。引き直しに交換個体は戻りません。両者完了後にメインから盾7枚を裏向きで置きます。

アンタップ→通常ドロー→土地1枚配置→メイン1→アタック→メイン2→エンド。最初の3つはターン開始時に一度だけ自動処理します。

アンタップは自分の場と土地を未使用へ戻し、召喚酔いを解除。先攻の最初の1ターンだけ通常ドローを省略し、後攻の初回を含めそれ以外は1枚。第1ターンも土地デッキ上から1枚を未使用で置きます。メイン2に入っても追加の自動配置はありません。効果追加はこのターン開始配置とは別です。

エンドでのみ、手札が7枚を超えたら持ち主が7枚まで選んでトラッシュへ送ります。完了まで次のターンへ進めません。壁打ちでは次も自分のターンで、壁打ちでは相手の自動ドロー・回復・ターン・操作対象切替はありません。相手はエンドを迎えないため、相手手札の超過では即時調整しません。Bot戦ではエンド完了後に相手へ渡し、各プレイヤーのターン開始にそのプレイヤーだけ回復・ドロー・土地配置を行います。進行はトークンと350ms抑止で二重処理を防ぎます。

## 両デッキのリフレッシュ

土地を配置する必要があるときに土地デッキが空なら、土地トラッシュだけを全て戻してシャッフルし、配置を続けます。場の土地を回収しません。両方空ならその配置だけを省略し、不足を表示します。複数枚も1枚ずつ処理。土地切れで敗北しません。通常の効果追加ではシャッフルせず、リフレッシュ時だけシャッフルします。

メインが空になったら、通常トラッシュを戻してシャッフルします。最後の1枚を引いても敗北しません。土地トラッシュ・手札・場・盾・除外は戻しません。複数ドロー・盾追加はリフレッシュ後も残りを続けます。実際に通常トラッシュを戻した直後に、固定位置（先頭）の自分の盾1枚をトラッシュへ送るペナルティを適用し、中断していた処理を続けます。その盾は手札へ加えず、トリガーを発動せず、直前に作り直した山札には混ぜません。盾0枚ならこの盾送りだけを省略し、追加敗北なし。固定位置と0枚境界はリフレッシュ処理に集約しています。

メイン・通常トラッシュが両方空なら、空のリフレッシュや盾ペナルティを繰り返さず、可能な枚数でその補充処理を終了。不足を画面・ログに表示し、続く別の効果は進めます。補充不能だけでは敗北を確定しません。土地リフレッシュには盾ペナルティなし。

解決中の呪文はチェックゾーンに保持し、途中のリフレッシュに混ぜません。全効果を終えてからトラッシュへ送ります。その時点でメインが空なら、その呪文も通常のリフレッシュ対象になれます。

## 緑カードの効果

- フェアリー・ライフ：土地デッキから1枚を未使用で追加。
- 豊潤フォージュン：同じ土地追加後、場の土地が5枚以下なら1ドロー。
- 竜の闘気：土地1追加→2ドロー→メインから裏向き盾1追加。
- 青銅の鎧：登場時に土地1追加。
- ナチュラル・トラップ：相手ユニット1枚を持ち主のトラッシュへ→その持ち主の土地デッキから土地1追加。
- 修復：メインから盾1追加。場の自分の土地が10枚以上なら計2枚。盾7枚は初期値で上限ではありません。
- バハムート：登場時、本人以外の両者のユニット・設置物をトラッシュへ。土地・盾・キャラ・サイドは対象外。軽減なし、追加のデメリットなし。
- 極楽鳥／エルフ：未使用かつ召喚酔いでなければ本人を横向きにし、支払いに任意の1色／緑1点を使用。独立したマナプールはありません。
- パンツァー：使用済みで登場。横向きでも相手の攻撃を引き付け、複数なら攻撃側が対象を選択。ブロッカーではありません。場の自分の土地5枚以上でトリガー。
- ドルツヴァイ：場の自分の土地枚数でパワーを更新。マッハファイターは登場ターンだけ召喚酔いでも相手ユニットを縦横問わず攻撃でき、本体には無効。戦闘勝利（同値の攻撃側勝利も含む）で土地1追加。
- 母なる大地：自分か相手のユニット1枚を持ち主のトラッシュへ。その持ち主が自分の土地枚数以下の軽減前合計コストのユニット1枚を自分の手札から無料で出してもよい。除去できなければ後半も行いません。登場時効果、召喚酔い、横向き登場も適用。トリガーは付けていません。
- ズンドコ晴れ舞台：自分のユニットが出るたび土地1追加。通常使用・トリガー・母なる大地・補助による新規登場で発動。本人・土地・他設置物の登場では発動せず、複数枚は各1回。場のシンボルは軽減用で、パワー・攻撃・ブロック・ブレイクはありません。設置物領域は枚数上限なし。Dスイッチや他フィールド登場による退場は未実装です。

条件とパワーに数えるのはマナゾーンにある土地カードだけです。土地デッキやマナ能力ユニットは土地枚数に数えません。

## 軽減・戦闘・トリガーの維持

コストは不特定と五色を別管理。場のユニット・設置物の同色シンボルで色指定だけを軽減し、不特定は変えず緑1を残します。横向きでも供給し、消費・タップしません。土地はシンボルなし。これから出す本人は数えず、上書き元は支払い時点では数えます。

支払い元には未使用土地と召喚酔いでない未使用のマナ能力ユニットを使えます。必須色を先に確保する自動案を変更可能。極楽鳥は色を選べます。各色の候補数には任意色源が重複しますが、実際に出すのは選んだ1色だけです。攻撃・ブロック・起動能力は使用済み状態を共有します。確定時に手札・配置先・上書き元・支払い元の所属／状態／色／重複を再検証し、取消・支払い不能・二重確定では消費しません。

ユニット7枠、満杯なら上書き元をトラッシュへ。召喚酔いと向きは別管理。通常攻撃は本体のみ、未使用のブロッカー1枚だけがブロックできます。新デッキへ独自にブロッカーは付けていません。確認用は手動追加で用意できます。

戦闘はパワー比較で低い側をトラッシュへ、同値は攻撃側有利。ダメージ蓄積・ブロック貫通なし。ノーシンボルは盾ブレイク0枚。ブレイクは先頭から必要個体を先に確定してすべて手札へ移し、その時点の条件を満たすトリガーを持ち主が好きな順に1枚ずつ処理します。途中で追加された盾は同じ攻撃で割りません。通常ドローでは発動しません。盾0枚の本体へ攻撃が通ったら攻撃側の勝利。最後の盾を割った攻撃や、残り枚数を超えたブレイクでは勝ちません。ブロック・攻撃対象変更によるユニット戦闘でも勝利になりません。ブレイク0のユニットでも、盾0枚への本体攻撃成功は勝利です。決着後は通常行動とBot処理を停止します。

今回補った試作用の順番は、ユニット本人の登場時能力→その登場時点で自分の場にあった各ズンドコの誘発です。バハムートで設置物が退場しても、登場時点で既に誘発した処理は続けます。

## 保存・構造・検証

状態の永続保存・旧状態の読み込みは行わず、起動ごとに新方式で生成します。確認付きリセットは両デッキ・両トラッシュ・配置・マリガン・ターン・使用状態・誘発キュー・選択・不足表示・ログを初期化します。旧60枚の状態を混ぜません。

cards.jsで色・種類・カード定義と効果列・メイン構成・土地構成を分離。deckLimitで個別上限を指定します。旧赤カード定義は再利用用に保持していますが、今回の開始デッキは緑のみ。mana.jsはコスト判定、game.jsはDOM非依存のゲーム・効果キュー、app.js／style.cssはUIです。

## Botの判断・非公開情報・安定性

Bot方針はbot.jsの独立した評価関数です。game.jsのobserveが作る投影データだけを受け取り、元のGameや状態配列は受け取りません。見られるのは自分の手札、公開ユニット・土地・設置物・トラッシュ、各領域の枚数、共通ルールから算出した合法な候補だけです。相手手札、両者の裏向き盾、両者のメイン／土地デッキの個体や並びは渡しません。相手の母なる大地の展開機会は手札枚数・土地数から大まかに評価し、実際の中身は見ません。

即時の直接攻撃勝利を優先し、危険時は盾追加・引き付け・除去を高評価。序盤は低コストの加速・マナ能力を残して重い初手を交換します。土地供給がない純加速は避け、複合効果は残るドロー・盾追加も評価。ズンドコの後にユニットを出せるか、母なる大地の自分の入れ替えと相手への展開機会、トラップが相手へ与える土地、バハムートの自軍損失、満杯時の上書き改善量も評価します。

支払いは人間と同じbeginPayment／配置先／confirmPaymentを使い、土地を先に使う案から色指定と軽減を満たします。召喚酔い・使用済みのマナ能力を使いません。勝てる攻撃役をマナへ使う損失も評価します。攻撃は強制対象・マッハファイター・パワー・ブレイク数を確認し、基本的に負ける攻撃は避けます。盾を割る順は多ブレイクを先に評価し、解決後の盤面から次を判断します。

ブロックは未使用ブロッカーだけ。直接敗北するなら不利でもブロックし、残りの攻撃役と盾を使ってそのターン全体の危険も評価します。同値は防御側が退場する扱い。トリガーは盾追加と防御を優先し、対象のない除去を使いません。手札超過では重複・現在の支払い元・土地供給・防御価値を評価し、終盤の不要な加速を捨てます。

Botは1回の合法な操作ごとに再評価します。bot-runner.jsは1タイマーだけで実行し、処理世代と対戦epochを確認。人間の入力待ち・決着では止まり、リセット・モード変更で古い処理を無効化します。1操作の表示間隔は140ms。想定外の実装エラー時は停止して再開ボタンを表示し、同じ失敗を無限に繰り返しません。これは通常のカード使用回数などを制限するルールではありません。

現時点では点数による貪欲な判断で、全行動列の探索や隠れたカードの確率推論はありません。複雑な連続展開、将来のマナ能力の保存、複数ブロッカーの最適配分、相手の未知のトリガーへの対応は最適とは限りません。
