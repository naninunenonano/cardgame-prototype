# cardgame-prototype

盤面試作 Ver.0.2。仮カードを自由に動かす壁打ち盤面で、マナにできるカードの範囲を比較します。

## 起動と方式

index.htmlをstyle.css・app.jsと同じフォルダに置いてブラウザで開きます。ビルド・外部アカウント・APIキーは不要です。iPhoneのファイルプレビューでは正常動作しない場合があるため、Webブラウザで利用してください。

開始時にA（全カード）かB（土地のみ）を選びます。両プレイヤーへ同じ方式を適用し、現在の方式を盤面上部に表示します。「方式を変更」で別方式を選ぶ場合は、確認後に共通サンプルへ初期化します。キャンセルした場合は方式・カード状態を保持します。同じ方式の選択では初期化しません。

## マナ比較

- 手札をタップ→「マナに置く」で同じプレイヤーのマナゾーンへ移動します。
- A：土地とそれ以外のすべてのカードを配置できます。
- B：「土地」以外は移動せず理由を表示します。汎用移動、他プレイヤーへの移動、他領域からの移動、仮カード追加でも同じ条件を適用します。
- 土地は表面の「◆ 土地」表示・二重枠・背景色で区別します。裏向きでは種類を表示しません。
- マナゾーンは総枚数と縦／横の枚数を表示します。カードの「縦横切替」と各プレイヤーの「すべて縦向き」を使えます。
- 移動時の表裏・縦横は保持します。縦横は手動の試作用操作です。

両方式・両プレイヤーは、同じ種類・名前・色・順序のサンプルから始まります（個体IDは別）。メインデッキ12枚中土地4枚、手札5枚中土地2枚、ライフ7枚中土地3枚、ルリグデッキ3枚、ルリグ1枚、シグニ各1枚を2枠に配置。マナは空です。すべて動作確認用の仮設定であり、確定ルールやデッキ構築条件ではありません。

1ターンの配置回数、土地配置コスト、発生マナ量、色による支払い、軽減シンボル、ダブルシンボル土地、土地・デッキの構築制限、自動支払いは実装していません。

## 引き継いだ壁打ち操作

上がプレイヤー2、下がプレイヤー1。操作対象を変えても位置は変わりません。両方の盤面を操作できます。

カードをタップ→操作欄で移動先選択→「移動」。枠に複数枚置けます。「一覧」から重なったカードを選びます。山札の先頭が上、末尾が下です。

表裏・縦横切替、拡大・裏向き内容確認、削除、ドロー、シャッフル、山札上下、仮カード追加、手札の公開範囲切替、コンパクト表示、確認付きリセットを利用できます。ドローも向きを保持するため、必要に応じて表裏を切り替えてください。手札の両者公開でも、個別の裏向き状態は維持します。秘密情報の管理機能ではありません。

手札が増えた場合は領域内を横スクロールします。再読み込みでは配置を初期化し、方式選択からやり直します。保存機能はありません。効果処理・勝敗・Bot・オンライン機能もありません。

## 変更箇所

app.jsのZONESが領域定義、initial()が共通サンプル、MODESとmanaError()が方式と配置条件です。エナゾーンの内部キーenergyを保持し、表示名をマナゾーンへ変更しました。style.cssのgrid-template-areasで配置を変更できます。
