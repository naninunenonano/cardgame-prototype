# cardgame-prototype — 盤面試作 Ver.0.13

緑・青・無色を使える静的HTML/CSS/JavaScriptのカードゲームです。Bot戦・壁打ち・デッキ編集保存に対応します。index.htmlをブラウザで開くか、`python -m http.server 8080`で起動してください。

## 戦闘と進行

- 初期ライフ30、初手5枚。マリガンは1回、選択した0〜5枚を山札下へ戻し、同枚数引いてシャッフル。旧シールドの配布・ゾーン・ブレイク・トリガーはありません。
- クリーチャーは攻撃力／現在体力を表示し、詳細に最大体力を表示します。既存パワーを1000で割り、攻撃力・最大体力へ同じ数値で変換しました。トークン・進化も同じです。
- プレイヤーへ攻撃が通れば攻撃力分のライフダメージ。ライフ0以下で敗北します。
- 通常攻撃は相手プレイヤーか横向きクリーチャー。戦闘では互いの攻撃力分のダメージを同時に受け、現在体力0以下の双方を破壊します。ダメージはターンをまたいで残ります。
- 攻撃・ブロックで横向きになり、自分のターン開始にアンタップ。ブロッカーは縦向きの1体が本体への攻撃を自身へ変更する既存方式です。存在するだけで攻撃を制限しません。パンツァーの引き付け能力は明示的な例外として維持します。
- 召喚酔い中は攻撃・自身を横向きにするマナ能力を使えません。スピードアタッカーは通常の対象へ攻撃可能。マッハファイターは登場ターンに相手クリーチャーの向きを問わず攻撃可能ですが、本体へ攻撃できません。
- 進化は元の向きを継承し、召喚酔いなし。新しい最上段の体力で登場します。場を離れて再登場したクリーチャーも体力を初期化します。
- ドルツヴァイは攻撃力・最大体力＝自分の土地枚数。土地増減時は受けたダメージ量を維持し、現在体力0以下なら破壊します。
- 色付きシンボルは対応する色指定コスト軽減専用。横向きでも供給し、消費せず、原則最低1を残します。不特定コスト・攻撃可否・ダメージに影響しません。土地は供給せず、本人の使用コストに本人を数えません。無色シンボルは削除しました。ジルの明示的な不特定軽減は別処理として維持します。
- メインが空なら通常トラッシュだけをシャッフルして補充します。除外・解決中・土地トラッシュなどは対象外。必要なカード取得時にリフレッシュでも補充できなければ敗北します。土地側は独立して土地トラッシュから補充し、両方空ならその土地配置だけ省略します。
- 毎ターンの通常ドローと土地1枚自動配置、先攻初回ドローなし、メイン1→アタック→メイン2→エンド、ユニット7枠、手札上限なしは維持します。

## デッキ・既存機能

通常40枚・土地20枚・サイドボード10枚枠を維持。プリセットのサイド内容は従来どおり空で、今回新規カードやサイド編集は追加していません。通常同名3枚、基本土地無制限、ジル・ペリドット・ツヴァイランサー・シェイパー・母なる大地・修復・バハムートは各1枚です。緑・青の公式プリセットだけが元の構成に対する既存例外を持ちます。複製後は通常制限を適用します。

デッキ編集は文明・種類・名前検索、詳細、枚数編集、保存・複製・削除に対応。localStorageへ保存し、不正デッキは下書きとして保持しますが開始を拒否します。予顕・対抗呪文・進化・トークン・運命生成と使用後消滅・追加ターン・ペリドット帰還・上書き配置・カード拡大・2秒の使用表示・公開履歴を維持しています。Botには相手手札や山札順を渡しません。壁打ち補助はBot戦には表示しません。

## カード能力の保留

《竜の闘気》《修復》《エメラル》《ホーリー・メール》《運命の翼》の旧シールド操作部分のみを一時無効にしています。カード自体・構築枚数・コストは維持し、残る効果を実行します。代替効果は未確定で、新しい回復や強化効果を割り当てていません。詳細と候補は [MIGRATION-v0.13.md](MIGRATION-v0.13.md) に記載しています。新シールドデッキ、キャラクターLv.4能力は実装していません。
