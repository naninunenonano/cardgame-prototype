# cardgame-prototype — 盤面試作 Ver.0.4

60枚の赤単色仮デッキ・各自1回のマリガンを備えた壁打ちツールです。未使用土地から支払えるコストを判定し、支払いとシグニへの配置をまとめて行えます。マナは土地のみです。

## 起動・操作

GitHub Pagesの既存URL、またはindex.htmlをブラウザで開きます。ビルド・APIキー・外部アカウントは不要です。ローカルではstyle.css・mana.js・app.jsも同じフォルダに置きます。iPhoneのファイルプレビューはJavaScriptが動かないことがあるため、公開URLをSafari等で開いてください。

開始時はプレイヤー1の初期手札を表示します。交換するカードをタップして複数選択し、「○枚交換する」で確定します。再タップで解除できます。「交換せず開始」でも完了になり、次のプレイヤーに進みます。両者が完了してから壁打ち画面が開きます。プレイヤーのタブで未完了の相手へ切替も可能です。

壁打ちでは両者のカードを操作できます。カードをタップし、下の操作欄で移動先を選んで「手動移動」。手札は「マナに置く」でも移動できます。土地以外のマナ配置は、専用操作・汎用移動・追加のすべてで拒否します。

表裏・縦横切替、内容の拡大確認、一覧選択、ドロー、シャッフル、山札上下、仮カード追加・削除、マナ一括縦向き、手札公開範囲切替、コンパクト表示を引き継ぎます。通常移動・ドローで表裏と縦横を保持するため、必要に応じて表裏を変更してください。裏向き内容確認は表裏を変えません。手札の両者公開でも個別の裏向き状態は維持します。

「初期状態へ」は確認後に両者の配置、追加カード、選択、マリガン状態を捨て、60枚の生成・シャッフル・初期手札からやり直します。キャンセルは状態を変えません。保存状態の読込機能はなく、再読み込みでも新規開始します。

## デッキ・カードデータ

両者は同じ構成です。赤・1コスト〜赤・12コストが各3枚（通常36枚）、赤の基本土地24枚、合計60枚。生成時に60枚・基本土地以外の同名3枚までを検証します。基本土地はこの同名制限から除外します。

カードはid・name・type・color・cost・mana・basic・origin・faceUp・restを保持します。同名もidで個体を区別し、originで初期の所属を追跡します。基本土地のcostはnullで、配置支払いはありません。効果・能力値は持ちません。

サイドボードは旧ルリグデッキと同じ領域で10枚枠です。初期は空で、独自のカードを生成しません。仮カード追加で試せます。上限10枚以外の構築・同名制限はサイドボードに適用しません。追加カードは壁打ち補助としてorigin=nullになり、生成した60枚と区別します。自由なデッキ編集画面はありません。

## 開始処理

1. 60枚を生成・検証し、プレイヤーごとにシャッフル。
2. 上から7枚を表向きで手札へ。山札53枚、シールドはまだ0枚。
3. 各自0〜7枚を選んで1回交換、または交換せず完了。
4. 交換対象を山札の下へ戻し、先に上から同数引いてから山札をシャッフル。
5. 両者完了後に、それぞれ上から7枚を裏向きのシールドへ配置。
6. 通常操作を解放。各自は手札7・シールド7・山札46、その他の領域は空。

通常操作は開始準備中に非表示／無効です。移動・追加も状態処理で拒否します。マリガンは同期処理の冒頭でプレイヤーを完了扱いにし、連打や古いボタンで再実行しません。先にシールドを置いたり、引き直す前にシャッフルしたりしません。

配置回数制限、独立したマナ生成操作・マナプール・ステップ消滅、軽減シンボル、効果・能力値、戦闘・勝敗、Bot、オンライン対戦は追加していません。土地の一括回復も手動です。

## マナ支払いと配置

手札の通常カードには「マナ支払い可」か不足理由を表示します。出せないカードは文字を暗くせず破線とラベルで区別します。カードをタップすると、合計不足・色不足を具体的に確認できます。空いているシグニ枠がなければ「配置先なし」と表示します。裏向き／非公開手札では内容と使用可否を表示しません。

1. 手札の通常カードを選び「場に出す」を押す。
2. 空いているシグニゾーンを選ぶ。
3. 必須色を先に確保した土地の自動案を確認。土地をタップして選び直せます。
4. 「支払いを確定して配置」で、選択土地を使用済みにし、カードを表向きで配置します。

キャンセル・閉じる・Escapeは土地とカードを変更しません。確定時に手札、空き枠、土地の所属・未使用状態・重複、総量・必須色を再検証し、すべて有効なときだけ一括処理します。同じ支払いセッションの再実行は拒否します。通常配置は1枠1枚ですが、壁打ち用の手動移動では既存どおり複数枚を扱えます。

「手動移動」は支払いを伴わない壁打ち操作です。「マナに置く」は土地専用で、配置回数制限はありません。使用済み土地は横向き＋「使用済み」、未使用は縦向き＋「未使用」と表示し、各自のマナゾーンに「未使用土地から出せるマナ」の合計と色別内訳を表示します。これは生成済みマナの貯留ではありません。手動の縦横切替や「使用済み土地をすべて未使用に戻す」で即時再判定します。

costは不特定genericと白・青・黒・赤・緑の数を分けたオブジェクトです。今回の赤・Nコストは不特定N-1＋赤1に設定。基本土地はcost=null、mana={color:'赤',amount:1}で、1枚を使用済みにして赤1点として支払います。今後の赤カード一般へこの配分を強制しません。コストの合計・色条件・自動案・支払い確認はDOM非依存のmana.jsへ分離しています。多色の確認はテスト用データのみで行い、通常の60枚デッキは変更していません。

## 構造

app.jsのCONFIGで初期枚数・上限、ZONESで名称・領域、buildDeckで仮デッキを定義します。finishSetupにシールド配置のタイミングをまとめています。CSSのgrid-template-areasで盤面配置を変更できます。既存の領域キーextra（サイドボード）、life（シールド）、energy（マナ）を再利用しています。
