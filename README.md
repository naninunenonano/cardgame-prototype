# cardgame-prototype

盤面試作 Ver.0.1。仮カードを置いて動かし、盤面の広さと配置を検討するための壁打ちツールです。

## 起動

このブランチをダウンロード／cloneし、`index.html`をブラウザで開いてください。ビルド・外部アカウント・APIキーは不要です。CSS・JSも同じフォルダに置きます。GitHub Pagesの設定は変更していません。

## 操作

- 上がプレイヤー2、下がプレイヤー1。操作対象を変えても位置は変わりません。両方の盤面を常に手動操作できます。
- カードをタップし、画面下部の移動先を選んで「移動」。枠の枚数や種類による制限はありません。
- 「一覧」で重なったカードを選びます。山札の先頭が上、末尾が下です。
- 「表裏切替」「縦横切替」「拡大・内容確認」「削除」を利用できます。内容確認は表裏の状態を変えません。
- 移動先にメインデッキ／ルリグデッキを指定し「山札の上へ」「山札の下へ」。通常移動も先頭へ入れます。
- 各メインデッキの「ドロー」で手札へ1枚移動。「シャッフル」で順番をランダム化します。移動・ドローでは表裏と縦横を保持するため、裏向きで引いたカードは必要に応じて表裏を切り替えてください。
- 「仮カード追加」で両者の任意の領域に名前・種類・色・表裏を指定して追加できます。
- 「手札表示」は表示上の公開範囲を切り替えます。個別に裏向きにしたカードは、両者公開でも裏向きのままです。壁打ち補助として、非公開手札や裏向きカードも選択後に内容確認できます。秘密情報の管理機能ではありません。
- 「盤面全体を見る」でコンパクト表示。手札が増えた場合は手札領域内を横スクロールします。
- 「初期状態へ」は確認後にサンプルを再配置します。再読み込みでも配置は初期化され、保存機能はありません。

## 仮設定と変更箇所

各自メイン12・手札5・ライフ7・ルリグデッキ3・ルリグ1・シグニ2・エナ2を配置しています。すべて動作確認用の仮設定であり、構築・初手・ライフ枚数や名称・ルールの確定を意味しません。

`app.js`の`ZONES`が領域の名称・枠数・一覧表示設定、`initial()`がサンプル、`style.css`の`grid-template-areas`がPC・スマートフォンの配置です。新しい領域を追加するときはZONESとCSSの配置定義を合わせて変更してください。個体ID・表裏・縦横はカードが保持し、移動先による自動制限はありません。アシストルリグ・効果処理・コスト・合法性判定・勝敗・Bot・オンライン機能はありません。
