# cardgame-prototype — 盤面試作 Ver.0.5

先攻プレイヤー1のターンだけを繰り返す壁打ちツールです。60枚仮デッキ、マリガン、シールド、色マナ支払いを引き継ぎ、ターン進行、土地配置1枚制限、攻撃／ブロックの使用済み管理を追加しています。

## 起動

既存のGitHub Pages URL、またはindex.htmlをブラウザで開きます。ローカルではstyle.css・mana.js・app.jsも同じフォルダに置きます。ビルド・APIキー・外部アカウントは不要です。iPhoneのファイルプレビューではJavaScriptが動かないことがあるため、Safari等で公開URLを開いてください。

## 開始とデッキ

両者に赤・1〜12コスト各3枚（通常36枚）と赤基本土地24枚、合計60枚を生成します。生成時に60枚・基本土地以外の同名3枚までを検証します。初期手札は7枚です。

マリガンは各自1回。手札をタップして0〜7枚を選び「○枚交換する」か「交換せず開始」で完了します。交換順序は「山札の下へ戻す → 上から同数ドロー → 山札をシャッフル」。戻した個体を同じ引き直しで再度引きません。両者完了まで通常操作は無効です。

両者が完了したら各自のシールドを7枚裏向きで配置し、自分（プレイヤー1）の先攻第1ターンを開始します。追加ドローはなく、初期配置は各自手札7・シールド7・山札46です。サイドボードは旧ルリグデッキと同じ空の10枚枠。中身を自動生成せず、サイド全体への同名制限も追加していません。

## 自分のターンだけを繰り返す

上部の固定表示に自分のターン数、土地の未配置／配置済み、未使用土地から出せるマナの合計と色別内訳を表示します。

「次のターン」は相手へ渡さず、再びプレイヤー1のターンを開始します。相手の自動ドロー・回復・行動はありません。「手動確認対象」をプレイヤー2に変えていても、自動で切り替えません。相手側の通常配置・攻撃等は停止し、手動移動や縦横確認は可能です。

ターン開始順序は次のとおりです。

1. 自分のシグニ3枠・ルリグ枠とマナゾーンだけを縦向きの未使用へ戻す。
2. 土地配置回数を0へ戻す。
3. 先攻第1ターンはドローなし。それ以降は山札上から1枚を表向きの手札へ。
4. マナと手札の使用可否を再描画する。

相手、手札、山札、シールド、サイドボード、トラッシュ、チェックの向きは回復処理で変えません。山札が空なら追加ドローせず、そのことを表示します（敗北処理は未実装）。

ターン操作には画面ごとのトークンと400msの連打防止を設け、同じ操作からの二重開始を拒否します。ターン更新時には選択と支払い途中の操作を失効させます。

## 通常の土地配置

自分の手札の土地をタップし「マナに置く」で配置します。1ターンに1枚まで。配置すると上部と手札に「配置済み」が表示され、通常配置は無効になります。手動で土地を手札へ戻しても配置回数を戻しません。次の自分ターンで再び配置可能です。土地以外は通常・手動どちらの経路でもマナゾーンに置けません。

通常配置の入口はplaceLandで、手札・土地・プレイヤー・回数を再確認します。通常の支払い配置から土地を移す経路はありません。

## マナ支払いとユニット配置

手札の通常カードには「マナ支払い可」、合計不足、色不足、配置先なしのいずれかを表示します。支払えないカードは文字を暗くせず破線とラベルで区別し、タップすると具体的な理由を確認できます。非公開手札と裏向きカードでは内容や使用可否を表示しません。

カードをタップ →「場に出す」→ 空きシグニ枠を選択 → 土地の自動案を確認・タップ変更 →「支払いを確定して配置」。必須色を先に確保し、残りで不特定コストを満たします。確定時に手札、配置先、土地の所属・未使用・重複、量・色を再確認し、成功した場合だけ一括で土地を使用済みにしてカードを配置します。キャンセル・閉じる・Escapeと支払い不能時は無変更。同じ支払いの二重実行を拒否します。

コストは不特定genericと白・青・黒・赤・緑を分けて保持します。今回の赤・Nコストは不特定N-1＋赤1という仮配分で、今後の赤カード全般へ強制しません。基本土地はcost=null、mana={color:'赤',amount:1}で、使用済みにした1枚から赤1点として支払います。独立したマナ生成・貯留・ステップ消滅はありません。量・色条件・自動案はDOM非依存のmana.jsに分離しています。

## 攻撃・ブロックと使用済み

自分の場（シグニまたはルリグ枠）の通常カードをタップして「攻撃」または「ブロック（確認用）」を選ぶと、横向きの使用済みになります。すでに使用済みなら両操作は再実行できません。ブロックは相手ターンを進めない壁打ちでの動作確認用です。

カードには向きに加えて「未使用／使用済み」の文字を表示します。次の自分ターンに自分の場と土地が回復します。攻撃対象、ブロック相手、戦闘・ダメージ・シールド破壊、勝敗、召喚酔い等は追加していません。

## ルール外の補助操作

「手動移動（ルール外の補助）」は支払い・土地のターン制限を無視します。土地配置回数に数えず、回数も戻しません。複数枚の場の配置を含め、盤面検討に利用できます。

仮カード追加、手動ドロー、手動縦横切替、手動回復も補助と明示しています。これらは通常の配置やターン開始とは別です。個別の縦横変更・手動回復でもマナと使用可否は更新します。追加カードは初期60枚とは別でorigin=nullです。追加による自由デッキ編集はありません。

既存の両者手札公開切替、一覧選択、表裏切替、裏向き内容確認、山札上下、シャッフル、削除、コンパクト表示を維持します。通常の手動移動と手動ドローは表裏と縦横を保持するため、必要に応じて手動変更してください。

「初期状態へ」は確認後に配置・追加カード・ターン数・土地回数・使用済み・処理中／選択状態・マリガン完了状態を初期化し、60枚生成と初手7枚からやり直します。キャンセル時は維持します。保存読込機能はなく、再読み込みでも新規開始します。

効果・能力値、軽減シンボル、戦闘結果・勝敗、Bot、オンライン対戦は未実装です。

## 構造

app.jsのCONFIGは枚数、ZONESは領域、buildDeckは固定デッキ、finishSetupはマリガン後のシールドと第1ターン、startTurnは回復・回数・ドロー順、placeLandは通常土地配置、useUnitは攻撃・ブロックの状態処理です。SOLO_PLAYERはp1に固定しています。既存キーextra（サイド）、life（シールド）、energy（マナ）を再利用し、CSSのgrid-template-areasで盤面を定義しています。
