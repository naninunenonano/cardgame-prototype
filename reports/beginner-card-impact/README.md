# 初心者Botの決定打調査

PR #56で調整した白・青・黒・赤のデッキを使用。異色6対面を各100戦、シード1〜100で実行し、各Botが50戦ずつ先攻になるようにした。ゲームとBotの実行処理には変更を加えていない。

## 判定方法

勝者の公開対戦ログを試合全体で走査し、実際に使ったカードを現行IDで集約する。採用リストのバニラとデッキ外の生成カードは候補外。発動・召喚・戦闘参加・効果のいずれかを確認した試合を使用試合とし、手札に引いただけ、マナに置いただけの試合は含めない。キャラクターは全候補の中で比較し、カードランキングから分離する。

同じ尺度を全色に使用。対プレイヤー実ダメージ1点を1点とし、オーバーキル分は除く。確定した相手クリーチャー破壊は2点＋対象攻撃力の半分（加算上限4）、バウンスなどは1.5点＋攻撃力の0.4倍（加算上限3）。ドロー1枚を1.25点、効果で追加したマナ1枚を1.5点。回復は回復前ライフ8以下で1.5倍、15以下で0.85倍、それ以上で0.4倍。登場・ブロック・生存中の相手へのダメージにも小さな盤面点を加え、発生元を特定できる自傷は1点につき0.45点を差し引く。最高点4未満、または1位と2位の差が1点未満なら判定不能。同点カードの掲載順はカードID順で、下位表の同点は使用試合数の多い順。

公開ログで発生元を追える効果を対象とした推定値。打ち消しの脅威、温存した手札、恒常的なダメージ軽減、間接的な展開の価値などは十分に反映されない。決定打0回でも使用価値がある。選出率の分母は勝敗・先後を問わない使用試合数。

## 再実行

```sh
node beginner-matchup-test.cjs 100 --impact > /tmp/beginner-impact.json
node beginner-card-impact.cjs reports/beginner-card-impact /tmp/beginner-impact.json
node beginner-card-impact-test.cjs
```

`BOT_PAIR=blueBeginner:redBeginner` のように絞って実行し、全対面のJSONをまとめて集計することもできる。
