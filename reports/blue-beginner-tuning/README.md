# 青初級Botのデッキ調整

基準は PR #60 マージ後の `b749f16`。対象は白・黒・赤の初級Botのみ。調整対象は青初級のメイン40枚。サイド10枚、シールド4枚は従来構成。

## 新規シードでの検証

各構成600戦。白・黒・赤に各200戦、青初級先攻100戦・後攻100戦。調整前と候補に同じ検証シードを割り当てた。予備比較には別の範囲を使用。

| 相手 | 調整前勝数／200 | 調整後勝数／200 | 調整後の先攻／後攻勝数 |
|---|---:|---:|---:|
| 白初級 | 51 | 63 | 45／18 |
| 黒初級 | 33 | 53 | 42／11 |
| 赤初級 | 34 | 58 | 48／10 |

採用案 **C**（コスモビュー+2、スノーマン+3）。総合勝率は **19.67% → 29.00%**。引き分け・異常終了は各構成0件。

前回の800戦では《コーライル》が17試合で使用・487回チャージ、《流浪の研究者》は54試合で使用・694回チャージ。これらの観測と既存AIの選択を踏まえ、青の供給源と実際に展開できる候補を比較した。

既存シミュレーターの5デッキモードを対面ごとに絞って使用。シード起点のみ予備比較3100001、最終検証4100001に置き換え、対面番号の間隔を10000とした。初手を決める先攻割当と乱数生成器は既存方式。

比較案Hも600戦で 186勝（31.00%）。対面勝数は白98・黒43・赤45。案Cは対面勝率が26.50〜31.50%に収まり、対面差が小さいため採用した。

別途36戦の観測では、案Cの《ルナ・コスモビュー》は22試合で使用・28回チャージ、《スノーマン召喚》は27試合で使用・31回チャージ。前者はブロッカー・青シンボル2・登場時ドローを持ち、手札10枚以上でG・ゼロ。後者はトークンで盤面を展開でき、既存AIに盤面枚数に応じた使用評価がある。
