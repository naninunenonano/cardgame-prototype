# 5デッキ総当たり・全採用カードの観測

基準はPR #59マージコミット `1f1c7e19e1717fcfda9592c88ed77b74fa31c22d`。白・青・黒・赤初級と青上級で10対面を各200戦、先攻を100戦ずつ割り当てた。カード、デッキ、Bot方針、対戦ルールに変更はない。

| ファイル | 内容 |
|---|---|
| [games.jsonl](games.jsonl) | 正常終了試合の試合ID・シード・先攻・勝者・ターン・ライフ・最終キャラレベル・決着理由 |
| [matchups.json](matchups.json) | 対面別の勝敗・引き分け・勝率・平均ターン |
| [decks.json](decks.json) | 総合および先後別成績 |

## 指標と読み方

- 勝率は勝利数÷正常終了数で、引き分けは分母に含める。平均ターンは対戦全体のターン通算。
- カードの実体を開始時のIDで追跡。呪文は使用宣言、クリーチャー・設置物は登場・設置成立、シールドは発動、キャラクターは成長を使用とする。同じ試合の使用イベントは複数回数える。カード実体ごとのマナチャージ・支払い供給も別集計。
- 判断機会は同じ観測時点で同名をまとめ、メインフェイズの合法候補と観測可能な応答・誘発選択で記録する。合法でも他の行動を選んだ時点を見送りとする。同じカードが次の判断で再び候補に上がることがある。シールドは候補に上がった選択窓と確認できた自動発動を集計。
- 未使用試合は、使用可能時点あり、支払い計画なし、その他の条件、観測機会なし、未特定の順で分類する。支払い計画なしと条件未達が重なる場合がある。サイドや特殊使用には支払い計画を公開しないものがあり、条件未達と区別できない。未使用かつ手札で見えたが判断窓がなかった試合は未特定に含む。
- 能力発動欄はカードを発生元として識別できた実行キュー項目数。複数処理の能力は複数項目になり、常在効果やログから識別できない発動は含まれない。キャラは実行時レベルに帰属。Lv別の使用回数は成長到達回数。
- 実績は戦闘の明示記録、カードの効果元参照、同一操作内の効果元から帰属を推定。ダメージ・除去・バウンス・手札破棄・ドロー・回復・ブロック・支払いを別集計。戦闘以外の効果元が途中で失われる連鎖、打ち消し、召喚制限、常在能力による防御などは完全には数値化できない。実績0は効果がなかったことを保証しない。`null` は対象外または分母なし。0は観測数0。
- 貢献度は100参加試合当たりの観測点。対プレイヤーダメージ1、対クリーチャーダメージ0.25、効果除去2、バウンス1.25、ハンデス1.5、ドロー1、回復0.5、ブロック1、支払い軽減0.25。マナ供給は別計上。勝ち・負け・引き分け別の観測点合計もJSONに保存。単純な試合中実績の比較であり、勝利への因果効果ではない。未使用の多いカード、常在・反応型カード、役割が限定的なカードは下位になりやすい。

## 再現

```sh
node beginner-matchup-test.cjs 200 --five > /tmp/five-deck.jsonl
node five-deck-report.cjs reports/five-deck-study /tmp/five-deck.jsonl
node five-deck-test.cjs
```

シードは対面番号ごとに100万1から10万刻みの範囲を割り当て、異常終了の補充でも試行ごとに進める。通常終了の試合順で先攻を交互に割り当てる。対面ごとに並列化するときは `BOT_PAIR=whiteBeginner:blueAdvanced` のように指定し、全ファイルを集計スクリプトに渡す。
