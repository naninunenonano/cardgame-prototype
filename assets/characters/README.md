# キャラクター画像

推奨1024×1536px（横×縦）、2:3。PNGまたはWebP。名前・レベル・能力は画像へ焼き込まず別表示する。

配置規則: `assets/characters/<内部ID>/lv0.webp` ～ `lv4.webp`（PNGなら `.png`）。内部IDは piruluk / redCaptain / blueSage / celestia。新キャラクターも同様にフォルダーを追加する。

`character-art.js` の `images` にキャラクターID→レベル0〜4→画像パスを登録する。未登録はnull。ゲーム本体・カード性能を変更する必要はない。同じパスで差し替えた場合はURLへ `?v=2` 等を付けてキャッシュを更新できる。

2:3の枠にobject-fit:containで全体表示。異なる比率の画像には余白が付き、引き伸ばし・トリミング・画像上への文字重ねはしない。未登録/読み込み失敗は同じ枠のNO IMAGE。ピルルクLv0の提供JPEG（1536×1024）を、画素・サイズを維持して可逆WebPへ変換して登録。Lv1〜4および他のキャラは未登録。

画像のエラーは表示側で扱い、ゲーム処理を停止しない。失敗パスをページ内で記憶し、毎回の再描画で不要な再読み込みを繰り返さない。修正後は再読み込みする。
