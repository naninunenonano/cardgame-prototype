## 共通処理

設置物ゾーンのshieldLink分類のみを数え、各プレイヤー最大5枚。通常の有料使用、無料設置、効果による配置、支払い確定時・実際の移動時に検証する。通常の設置物は対象外。リンクに上書き用スロットを指定できない。

自分のターン中、相手の設置物一覧からリンクを選び、共通破壊を選択する。元の合計コストの半分（切り上げ）を無色で支払う確認画面を開き、マナの選択を変更・キャンセルできる。シンボル軽減は経由しない。回数制限なし。対象が場を離れて戻った場合も古い選択は受け付けない。

Lv4の5択は誘発時点で任意選択。各モードを解決前に使用済みにするため、④の無料設置で再誘発しても同じモードは選べない。5枚目の設置は誘発し、回復・ドロー・手札追加・回収は使えるが、無料設置は選べない。6枚目を作る起動・無料設置は支払い前に拒否する。Lv3は自分のターン1回、Lv4は独立した制限。現在レベルのみ有効。

紋章トークンは通常カードの所持・パック・生成・デッキ採用から除外。場を離れる場合は移動先に残らず消滅する。自分のターン終了時には自分の各ゾーンの専用紋章が消滅する（手札に生成する断罪の紋章も対象）。相手の紋章や隼の軌跡のt7にはこの終了処理を適用しない。既存のSL設置誘発は実際の設置時に統一し、無料設置・トークン設置でもザゼ・ゼーン等と連携する。
