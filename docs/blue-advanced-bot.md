# 5000VTとBotデッキの更新

- 《飛翔龍 5000VT》を青ORの `bo1` に移行。青1＋無色7、12/12、青シンボル2、通常3枚まで。双方のクリーチャー・設置物で無色部分のみ軽減。旧ID `no1`、`vt5000`、`sbno1`、`sbnl2` は読み込み時に移行し、画像登録先は `images/cards/bo1.png`。
- 同名の赤アパッチ2種をカード管理表の黒仕様に移行。旧 `rn17` は `kn9`、旧 `rn21` は `kn10` に読み替える。復讐状態は現在ライフ15以下で判定する。
- 初級赤Botはアパッチ各3枚を《襲撃者エグゼドライブ》《初級ゴーレム》各3枚に交換。速攻と自傷のない展開枠を確保する。
- 初級黒Botは《傭兵》《見習い学者》各3枚を黒アパッチ各3枚に交換。PR #58では傭兵の使用時勝率差は＋7.23ptで黒の通常カード中最小。見習い学者は＋18.16ptで決定打0回。どちらも正の関連があるが、同じ低コスト帯で復讐と連動する攻撃手段を増やし、登場時ドローの《グレンニャー》《流浪の研究者》は維持する。

青上級Botは通常対戦の相手選択に追加。通常40枚、サイド10枠、シールド4枚を使用する。現行ゲームは手札をマナに置くため土地デッキは存在しない。判断処理は共通Botを基に、妨害先・全体バウンス時の盤面差・手札10枚でのG・ゼロを評価する。アルマーの能力、覚醒、侵略、革命チェンジ、対抗呪文の応答は既存のルール・選択処理を利用する。

[PR #58のカード使用率](../reports/beginner-card-usage/)は当時のデッキとカードの集計。再現するには基準コミット `fc9000669922f11f2877fa9b3b33ad0dbf53fc9c` を使用する。
