# カードIDの採番と移行

基準mainは f383ddbce15c9fd5752ca1658d8419595e0f5236。変更日は2026-11-20。

「全カード一覧」で現行IDとカード名を管理する。「ID管理」Aの次回採番番号を確認し、使用中・予約済み・欠番の番号を再利用しない。登録時は全カード一覧、カード案、Bot関連の参照とid-registry.jsのhighWaterMarksを更新する。

新IDの採番は node id-allocation.cjs に名前・色・レアリティ・区分を渡す。旧LEGEND入力はURに正規化される。ID変更時はaliasesとmigrationHistory、永久欠番のretiredIdsを更新する。両面カードの有効な関連IDは維持する。

## 追加確定（2026-11-20）

フォーミュラ・シンクロンとフルール・ド・バロネスは無色。記載コストはそれぞれ無色2・無色10。能力、攻撃力、体力、採用枚数は維持する。

|カード名|旧ID|新ID|理由|
|---|---|---|---|
|フォーミュラ・シンクロン|sbws2（実装）／sbns2（管理表）|sbns3|無色確定と最大使用番号の次から採番|
|フルール・ド・バロネス|sbwo1（実装）|sbno3|無色確定。sbno1は5000VTの永久欠番、sbno2はヌメロニアが使用中|

sbws2・sbns2・sbwo1は永久欠番とし、新IDへ読み替える。管理表のバロネスに重複記載されていたsbno1はsbno3へ訂正するが、保存データのsbno1→bo1（5000VT）は維持する。

管理表の予約済みru1は“轟轟轟”ブランド用として確保する。未実装のキャラクターredrushは独立した文字列IDとして維持する。
