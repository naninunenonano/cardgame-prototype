## 処理とタイミング

- 通常の設置物の支払い・設置・除去・シンボルを再利用。
- セイント・キャッスルは1回のダメージイベントを1回だけ置換し、場の1枚をトラッシュへ。もとのダメージが0でも適用。直接ライフ減少とルールダメージは対象外。複数枚があっても、置換済みイベントにさらに置換を繰り返さない。
- ウィリデの軽減は無色のみ。支払い確定時も場を再確認。相手自身のターン中の召喚・詠唱・設置宣言で、各個体にターン識別子を記録して1ドロー。コストを払わない単なる蘇生・直接登場とは区別する。
- ザゼ・ゼーンは開始時の自動アンタップのみ禁止。タグ付き設置物の登場でアンタップし3択。相手の次の開始時だけアンタップを飛ばす効果と、次の自分の開始時まで離場できない効果を個別管理。ダメージは回復しない。離場保護の終了後は致死ダメージを通常どおり判定する。
- ミスト・リエスは両者のクリーチャー・トークン登場を参照し、設置物ごとに任意ドロー。任意ドローUIは開始時・登場時にも使える一般的な表記に修正。
- シルヴァー・グローリーはクリーチャー同士の戦闘ダメージのみ防ぐ。効果ダメージは防がず、ドレインは実際に与えたダメージで計算。
- 設置物の開始時能力を既存キューへ統合。開始時に誘発した処理と、その後の離場・再登場の世代を区別し、新たに設置した別世代を誤って破壊しない。開始時より前に場を離れた隼の軌跡は誘発しない。
- 隼トークンは白・コスト2・2/1・SA・シンボルなし。トークンにはレアリティを割り当てず、既存6種類も現在のレアリティをなしへ統一。既存トークンの能力・数値は維持。採番は専用台帳t7、通常カード連番とは独立。パック・所持・採用・生成・分解に混入させず、離場時に消滅する。
