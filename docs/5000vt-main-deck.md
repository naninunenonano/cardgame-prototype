# Ver.0.41 — 5000VTのメインデッキ指定を修正

ユーザーの訂正に従い、飛翔龍5000VTをサイド専用からメイン専用へ修正。

- 無色・OR・元コスト8・12/12・青シンボル1・登場時バウンス/次の相手ターンの召喚制限は維持。
- IDは通常デッキの無色OR `no1`。`sbno1`を廃止・再利用禁止とし、`sbnl2`/`sbno1`/`vt5000`は`no1`へ互換移行。
- PNG登録先は `images/cards/no1.png`。基準mainに対象PNGは未登録。画像変更なし。
- クリーチャー数の無色コスト軽減を通常召喚でも処理。両者のクリーチャー・トークンを数え、キャラクターは数えず、最低0。Lv4のサイド専用3軽減は適用しない。
- サイドの使用回数を消費せず、破壊・バウンスは通常のトラッシュ/手札へ。マナチャージ可能。サイド編集・サイドからの使用は不可。
- 既存の保存デッキに旧VTがサイド採用されていた場合、同じ枚数をメインへ移す。所持数・素材・通貨・他のカードを失わない。移行は冪等。40/10枚から外れる場合は下書きとして保持し、編集画面の枚数エラーで調整を促す。勝手なカード破棄・入替はしない。
- 壁打ち用アルマー構成はVTの枠を既存の《知識の使者》1枚へ入れ替え、10枚・キャラクター1枚を維持。既存の通常デッキプリセットは維持。

vt-main-test.cjs、vt-main-browser-test.cjsで分類・ID・編集・保存移行・通常召喚と軽減・マナ・行き先・サイド使用回数の独立を確認。既存のVTバウンス/制限テストは通常召喚からの解決へ更新。ORの経済・演出仕様は維持。
